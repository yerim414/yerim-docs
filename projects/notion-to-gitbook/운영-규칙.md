# 운영 규칙

이관은 끝이 아니라 시작이다. 앞으로 문서가 계속 쌓일 텐데,
규칙을 남겨두지 않으면 **6개월 뒤에 똑같은 상태로 돌아간다.**

Python이 54개까지 늘어난 것도 처음부터 그랬던 게 아니라 하나씩 추가하다 보니 그렇게 된 것이다.

## 글 쓰는 경로가 두 개다

Git Sync는 양방향이다. 웹 에디터에서 써도 되고 저장소에서 써도 된다.

| | GitBook 웹 에디터 | 저장소 |
| --- | --- | --- |
| 반영 | 저장하면 저장소로 자동 커밋 | 푸시하면 GitBook이 가져감 |
| 이미지 | 붙여넣기로 바로 삽입 | 직접 넣고 경로 작성 |
| 강점 | 글 하나 쓰기 | 구조 개편, 일괄 수정 |

**평소 글쓰기는 웹 에디터, 구조 작업은 저장소**로 정했다.
이미지가 많은 글을 쓰는데 저장소에서 하면 파일을 옮기고 상대경로를 쓰는 게 매번 번거롭다.

### 주의할 점

**웹에서 글을 쓰면 저장소에 커밋이 자동으로 생긴다.**
로컬이 뒤처진 상태가 되므로 저장소 작업 전에 반드시 받아온다.

```bash
git pull origin master
```

이걸 빼먹고 작업하면 충돌을 처리해야 한다. 양방향 동기화에서 가장 자주 걸리는 함정이다.

## 문서를 추가할 때

저장소에서 만들 경우 **세 곳을 손봐야** 사이드바에 뜬다.

1. 문서 파일 생성
2. `SUMMARY.md`에 링크 추가
3. 섹션 `README.md` 또는 그룹 페이지에 링크 추가

하나라도 빠지면 누락된다. 실제로 이관 직후 `U-01`~`U-04`가 이 이유로 보이지 않았다.

정렬은 **라틴 문자 먼저, 그다음 한글**이다.

## 12개를 넘으면 묶는다

한 메뉴의 직속 하위가 12개를 넘으면 주제별 그룹으로 나눈다.

그룹을 만들 때는 **파일을 옮기지 않는다.** `groups/` 아래에 인덱스 페이지만 만들고
`SUMMARY.md`에서 중첩시킨다. GitBook의 목차 중첩은 파일 구조와 무관하게 동작하므로
이렇게 하면 URL이 바뀌지 않는다.

중첩은 **3단계까지만** 쓴다. GitBook 공식 권장이기도 하고, 그 이상은 찾기 어려워진다.

## 문서를 지우거나 옮길 때

URL이 사라지면 `.gitbook.yaml`에 리다이렉트를 남긴다.

```yaml
redirects:
  이전/경로: 새/경로.md
```

## 빈 문서는 숨긴다

내용이 없는 문서는 `SUMMARY.md`에서 빼서 사이드바에 노출되지 않게 한다.
파일은 지우지 않는다. 대신 세 가지를 남긴다.

1. 파일 상단에 초안 안내 문구
2. `DRAFTS.md`에 목록과 되돌릴 위치
3. `CLAUDE.md`에서 `DRAFTS.md`를 가리키게

시간이 지나면 **왜 이 문서가 목차에 없는지 잊어버리기 때문**이다.

## 제목에 기호를 쓸 때

`**`, `__`처럼 쌍이 되는 기호는 마크다운이 서식으로 해석한다. 백틱으로 감싼다.

```markdown
# `__del__` vs `__exit__`
```

## 자격증명

문서에 실제 값을 쓰지 않는다. `YOUR_PASSWORD` 같은 플레이스홀더를 쓴다.
사설 IP(`192.168.x`)는 민감정보가 아니므로 그대로 두어도 된다.

## 검증

구조를 바꾼 뒤에는 링크가 깨지지 않았는지 확인한다.

```bash
# SUMMARY의 링크가 실제 파일과 일치하는가
grep -oE '\]\([^)]+\.md\)' SUMMARY.md | sed 's/](//;s/)//' | while read f; do
  [ -f "$f" ] || echo "MISSING: $f"
done

# 목차에 등록되지 않은 문서가 있는가
find . -name "*.md" -not -path "./.git/*" | sed 's|^\./||' | while read f; do
  grep -qF "$f" SUMMARY.md || echo "NOT LINKED: $f"
done
```

## 규칙을 어디에 두는가

`CLAUDE.md`에 정리했다. AI 도구가 이 저장소를 다룰 때 참조하는 파일이지만,
사람이 읽기에도 그대로 쓸모가 있다.

규칙을 머릿속이 아니라 **저장소 안에** 두는 게 핵심이다.
