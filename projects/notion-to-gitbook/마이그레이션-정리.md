# 마이그레이션 정리

Notion에서 마크다운으로 내보내면 파일은 다 나온다. 문제는 **그 다음**이었다.

## 1. 목차에서 누락된 문서

내보내기 직후 문서 4개가 어느 목차에도 연결되어 있지 않았다.

```
infra/linux/u-01-root계정-접속-제한.md
infra/linux/u-02-패스워드-복잡성-설정.md
infra/linux/u-03-계정-잠금-임계값-설정.md
infra/linux/u-04-패스워드-파일-보호.md
```

파일도 있고 이미지도 `.gitbook/assets`에 들어와 있는데, `SUMMARY.md`와
섹션 `README.md` 양쪽에 링크가 없어서 **사이드바에 아예 뜨지 않는 상태**였다.

GitBook은 파일이 있다고 페이지를 보여주지 않는다. `SUMMARY.md`에 등록된 것만 목차에 올라간다.
그래서 검증을 스크립트로 돌렸다.

```bash
# 모든 md 파일이 SUMMARY에 등록되어 있는지
find . -name "*.md" -not -path "./.git/*" | sed 's|^\./||' | while read f; do
  grep -qF "$f" SUMMARY.md || echo "NOT LINKED: $f"
done
```

반대 방향(SUMMARY에는 있는데 파일이 없는 경우)도 함께 확인했다.
이후 구조를 바꿀 때마다 이 두 검사를 돌려서 링크가 깨지지 않았는지 확인했다.

## 2. 마크다운이 먹어버린 제목

Notion에서 기호가 들어간 제목이 그대로 넘어오면서 마크다운 서식으로 해석됐다.

```markdown
# __del__ vs __exit__
```

`__`가 쌍으로 묶이면서 **del** vs **exit**로 굵게 렌더링됐다. 언더스코어가 사라진 것이다.

```markdown
# **(딕셔너리 언패킹)
```

이쪽은 `**`가 통째로 사라져 `(딕셔너리 언패킹)`으로 표시됐다.

제목에 기호가 있으면 백틱으로 감싸야 한다.

```markdown
# `__del__` vs `__exit__`
```

전체 문서의 H1을 훑어서 `*`, `_`, `~`, 백틱이 포함된 제목을 찾아냈다.
`sql_mode`나 `insert() 후 _id return`처럼 언더스코어가 하나뿐이라 쌍이 되지 않는 것들은
정상 렌더링되므로 손대지 않았다.

## 3. 중복 문서

같은 주제가 여러 문서로 쪼개져 있었다. Notion에서 그때그때 새 페이지를 만들다 보니 생긴 일이다.

| 병합한 문서 | 병합 대상 | 이유 |
| --- | --- | --- |
| 딕셔너리 언패킹 | Unpacking | 같은 주제, 13줄 vs 53줄 |
| 가상화 activaet | 가상환경 | 제목 오타(`activaet`), 내용은 가상환경의 트러블슈팅 항목 |
| requests verify 변수 | request 라이브러리 | requests 옵션 설명 |
| requests 요청 시 redirection 방지 | request 라이브러리 | requests 옵션 설명 |

`request 라이브러리` 하나에 GET/POST/PUT/DELETE가 이미 정리되어 있었으므로,
`verify`와 `allow_redirects`는 그 문서의 하위 절로 넣는 게 맞았다.

## 4. 분류가 어긋난 문서

`데이터 구조 & 컬렉션` 그룹의 유일한 자식이 `파일 open`이었다.
자료구조와 관계없는 주제인데다, **자식이 하나뿐인 그룹은 계층만 깊게 만든다.**

`파일 & 로그` 그룹으로 옮겼다. 단 파일은 이동하지 않고 목차상 위치만 바꿨다.
이유는 [정보 구조 재설계](정보-구조-재설계.md)에 정리했다.

## 5. 빈 문서

제목 한 줄만 있고 내용이 없는 문서가 7개 있었다. 사이드바 자리는 차지하는데 열면 빈 페이지다.

지우지 않고 **목차에서만 빼기로** 했다. 언젠가 채울 문서들이라 파일을 없앨 이유가 없었다.

* `SUMMARY.md`와 섹션 README에서 링크 제거 → 사이드바에서 사라짐
* 파일 상단에 초안 안내 문구 삽입 → 열어보면 바로 알 수 있음
* `DRAFTS.md`에 목록과 "어디에 다시 등록해야 하는지" 기록

세 겹으로 남겨둔 이유는, 시간이 지나면 **왜 이 문서가 목차에 없는지 잊어버리기 때문**이다.
