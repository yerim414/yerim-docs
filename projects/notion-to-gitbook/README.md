# Notion → GitBook 문서 이관

Notion에 흩어져 있던 기술 문서를 GitBook으로 옮기고, 옮기는 김에 구조와 보안까지 정리한 기록.

## 왜 옮겼나

Notion은 쓰기엔 편했지만 몇 가지가 걸렸다.

* 문서가 늘어날수록 **검색과 탐색이 느려졌다**
* 외부에 링크를 공유하기 애매했다
* 버전 관리가 안 되니 **뭘 언제 고쳤는지 남지 않았다**

GitBook은 Git 저장소와 양방향 동기화가 되니, 글은 웹 에디터에서 편하게 쓰고
구조 변경이나 일괄 수정은 코드처럼 다룰 수 있겠다고 판단했다.

## 결과 요약

* 평면으로 늘어져 있던 사이드바를 **주제별 그룹으로 재편** (Python 54 → 9)
* **기존 문서 URL을 하나도 바꾸지 않고** 구조만 변경
* 마이그레이션 데이터에 섞여 있던 **평문 자격증명을 히스토리에서 제거**
* 이후 유지보수를 위한 **운영 규칙 문서화**
