# 간단한 인사 봇 만들기

간단한 인사 봇 만들기

Bot token 발급까지 완료 되었다면 코드 작성하기

```python
import discord
from discord.ext import commands
import random
from dotenv import load_dotenv
import os

load_dotenv()
TOKEN = os.getenv("DISCORD_BOT_TOKEN")

intents = discord.Intents.default()
intents.message_content = True

bot = commands.Bot(command_prefix="!", intents=intents)

@bot.event
async def on_ready():
    print(f"✅ 봇 로그인: {bot.user}")

@bot.event
async def on_message(message):
    if message.author == bot.user:  # 봇이 자신의 메시지에 반응하지 않도록 설정
        return

    if "안녕" in message.content:
        responses = ["안녕하세요! 😊", "반가워요!", "안녕~! 좋은 하루 보내세요."]
        await message.channel.send(random.choice(responses))

    elif "고마워" in message.content:
        await message.channel.send("천만에요! 😆")

    elif "잘자" in message.content:
        await message.channel.send("좋은 꿈 꾸세요! 😴")

    await bot.process_commands(message)  # 명령어도 함께 처리

bot.run(TOKEN)
```

**Process**

```python
- Bot이 켜졌을 때 실행되는 이벤트 → on_ready
- 유저가 메시지를 보냈을 때 실행되는 이벤트 → on_message
- 그 안에서 특정 키워드가 있으면 → 챗봇이 응답
```

코드 설명

```python
intents = discord.Intents.default()
intents.message_content = True  # 유저가 보낸 메시지 내용을 읽을 수 있도록 설정
```

**Intents**는 디스코드가 어떤 정보를 봇에 전달할지를 결정하는 설정

`message_content=True`를 해줘야 **유저의 일반 채팅**을 읽을 수 있다. 

Default는 False이니 True로 설정

```python
bot = commands.Bot(command_prefix="!", intents=intents)
```

“!” 명령어로도 입력하면 처리할 수 있게 설정

! 말고도 다른기호도 가능 @ 같은거..

```python
@bot.event
async def on_message(message):
```

메세지를 보냈을때의 처리

디스코드에서 메세지를 보내면 디스코드 서버가 해당 정보를 이 함수에 자동으로 전달함

`@bot.event` 가 디스코드 이벤트를 감지하여실행하는 함수, 그 안의 파라미터는 디스코드가 넘겨주는 값!

```python
if message.author == bot.user:
    return
```

봇이 자기가 보낸 메세지는 반응하지 않도록 처리

```python
if "안녕" in message.content:

```

“안녕” 이라는 단어를 포함한 메세지를 보내었을 때 미리 정의한 응답 중 하나를 랜덤하게 출력함

 

```python

```
