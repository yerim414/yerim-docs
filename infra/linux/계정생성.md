# 계정생성

아래의 내용들은 root권한으로 진행

### 사용자 조회

```bash
cat /etc/passwd

cut -d: -f1 /etc/passwd 

#:를 구분자로 사용하여 첫 번째 필드만 출력
```

저걸로 조회하면 내가 만들지 않은 처음보는 계정들이 많을것이다. ftp, sshd 머 이런게 많다

이런 시스템 계정을 제외하고 확인하려면

```bash
cat /etc/passwd | grep /bin/bash
```

### 사용자 생성

사용자 생성엔 두가지가 있다 useradd와, adduser

useradd는 **사용자 계정 생성만**을 한다 다른 설정들은 따로 작업을 해주어야 한다.

adduser는 작업이 필요없다. 일반적인 디폴트 설정을 따른다.

```bash
adduser yerim
```

### 사용자 삭제

삭제하는 유저의 홈 디렉토리는 직접 삭제해줘야 한다.

```bash
deluser yerim
```
