# vim 명령어

자주쓰는것만!!

| 목적 | 명령어 |
| --- | --- |
| 파일 열기 | `vim 파일명` |
| 입력 모드 시작 | `i` (커서 앞 삽입), `a` (뒤에 삽입), `o` (아래 줄 생성) |
| 저장 (명령 모드) | `:w` |
| 저장 후 종료 | `:wq` 또는 `ZZ` |
| 강제 종료 (저장 안 함) | `:q!` |
| 줄 번호 표시 | `:set number` |
| 줄 번호 제거 | `:set nonumber` |
| 검색 | `/검색어` (다음: `n`, 이전: `N`) |
| 현재 위치 저장 후 되돌리기 | `u` (undo), `Ctrl + r` (redo) |
| 복사 (일반 모드) | `yy` (한 줄), `y2y` (2줄) |
| 붙여넣기 | `p` |
| 삭제 | `dd` (한 줄), `d2d` (2줄) |
| 파일 여러 개 열기 | `vim 파일1 파일2` (`:n`, `:prev`로 이동 가능) |

입력 모드 진입 : `i`, `insert` 키

일반 모드 : `esc`

명령모드 : 일반 모드에서 `:` 입력
