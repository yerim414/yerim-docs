# vi, vim

vi와 vim은 모두 텍트스 편집기 이지만 큰 차이가 있음

## vi

- visual editor의 약자로 unix 시스템용으로 만들어진 기본 텍스트 편집기이다.
- 거의 모든 unix및 리눅스 시스템에 기본으로 설치되어있다
- 기능은 최소한으로 구성되어 있다.

## vim

- vi improved의 약자, vi를 향상 시켰다는 의미이다.
- vi 의 기능을 크게 확장 하였다.

주요 차이점

| 항목 | `vi` | `vim` |
| --- | --- | --- |
| 기본 제공 여부 | 모든 UNIX 계열 OS에 내장 | 일부 리눅스에는 기본 설치 / 직접 설치 필요할 수 있음 |
| 기능 확장성 | 제한적 | 매우 풍부 (플러그인, 스크립트, 자동 완성 등) |
| **문법 하이라이팅** | ❌ 없음 | ✅ 있음 |
| **복수 언어 지원** | ❌ 없음 | ✅ 있음 |
| **Undo/Redo** | 1단계 Undo만 가능 | 다단계 Undo/Redo 가능 |
| **탭/윈도우 분할** | ❌ 불가능 | ✅ 가능 |
| **도움말 시스템** | 제한적 | `:help`로 다양한 문서 열람 가능 |
| **플러그인 시스템** | ❌ 없음 | ✅ 강력한 시스템 지원 |
| **검색 강조 표시** | ❌ 없음 | ✅ 가능 (`set hlsearch`) |

vim을 설치하는 방법

```python
sudo yum install vim

sudo dnf install vim
```
