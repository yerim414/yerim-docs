# 리눅스 파일 및 디렉토리 명령어

Centos, rockyLinux 기준

## 현재 디렉토리 파일과 목록 조회

```jsx
ls -al : 현재 디렉토리의 모든 파일과 디렉토리를 자세히 보여주는 명령어
-a : 숨겨진 파일 및 디렉토리 모두 보여줌
-l : 파일 및 디렉토리에 대한 정보 보여줌(권한, 소유자, 그룹, 크기, 생성일자 등)
```

## 디렉토리 생성 및 삭제

```jsx
mkdir directory_name : 새로운 디렉토리 생성

rmdir directory-name : 빈 디렉토리를 삭제

rm filename : 파일이나 디렉토리를 삭제

rm -rf directory_name : directory_name과 그 안의 모든 파일 및 디렉토리를 삭제

-r : 디렉토리 삭제
-f : 강제삭제

rm -rf 명령은 삭제한 파일을 되돌릴 수 없다!!
```

## 파일 복사

```jsx
cp file.txt file_copy.txt : 파일을 새로운 이름으로 복사

cp file.txt /path/to/destination : 파일을 다른디렉토리로 복사하기

cp -r directory1 /path/to/destination : 디렉토리 복사

원본파일 이름에 여러개를 적어 한번에 복사도 가능하다!!
```

## 파일 이동하기 이름 변경하기

```jsx
mv file.txt /path/to/destination/ : 파일 이동하기

mv old_name.txt new_name.txt : 파일 이름 변경하기

mv directory1 /path/to/destination : 디렉토리 이동
```

## 파일 조회

```jsx
cat filename : 파일 내용을 화면에 출력
```
