# 로케일 설정

도커 컨테이너 내부에서 vi 를 하여 파일을 보고 있는데 한글로 된 내용이 다 깨져 있다.

## **❤️ 도커 컨테이너에서 한글이 깨지는 주요 원인**

1. **로케일 설정 문제**
    - 기본값이 `C` 또는 `POSIX` 로케일로 설정됨
2. **한글 폰트 미설치**
    - GUI나 한글 폰트 부재시 표시 불가
3. **환경 변수 미설정**
    - `LANG`, `LC_ALL` 환경변수를 UTF-8로 설정 필요

## **❤️ 해결방안**

도커파일에서 로케일 설정을 해주면된다. rocky linux 기준

```bash
RUN dnf install -y glibc-langpack-en glibc-langpack-ko
```

먼저 로케일 패키지를 설치해준다. 혹시 몰라 영어도 설치해주었다

```bash
# 로케일 환경 변수 설정
ENV LC_ALL=ko_KR.UTF-8
ENV LANG=ko_KR.UTF-8
ENV LANGUAGE=ko_KR.UTF-8
```

로케일 환경 변수만 설정해주면 된다. 간단하다.

## **❤️ 정리**

도커 컨테이너 내부에서 한글이 깨지는 주된 원인은 한글 환경변수가 설정되지 않았기 때문입니다. 이는 로케일 패키지 설치와 환경변수 설정으로 해결할 수 있습니다.
