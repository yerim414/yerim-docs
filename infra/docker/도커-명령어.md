# 도커 명령어

자주쓰는, 알아두는 도커 명령어

## 이미지

```yaml
docker images : 도커 이미지 조회
```

```yaml
docker search [image name] : 도커허브에서 이미지 검색
```

```yaml
docker image pull [image name] : 도커허브에서 이미지 가져오기
```

```yaml
docker save -o [파일이름.tar] [image name:version] : 도커 이미지 tar 압축
```

```yaml
docker load -i [파일이름.tar] : 압축된 이미지 로드
```

```yaml
docker commit [container name] [image name:version] : 도커 컨테이너를 새 이미지로 생성 
```

```yaml
docker rmi [image name:version] : 이미지 삭제 (삭제하려는 이미지가 사용중이면 삭제가 안됨!)
```

## 컨테이너

```yaml
docker ps : 실행중인 컨테이너 목록 확인
```

```yaml
docker ps -a : 실행중 & 종료된 모든 컨테이너 목록 확인
```

```yaml
docker start [container name or id] : 컨테이너 실행
```

```yaml
docker stop [container name or id] : 컨테이너 종료
```

```yaml
docker stop $(docker ps -aq) : 모든 컨테이너 중지
```

```yaml
docker restart [container name or id] : 컨테이너 재시작
```

```yaml
docker exec -it [container name or id] /bin/sh : 컨테이너 내부 접속
(터미널 세션을 연결하지 않음, -it 명령으로 대화형 모드 실행)
```

```yaml
docker attach [container name or id] : 컨테이너 내부 접속
(컨테이너가 터미널에 종속, 터미널에서 나오면 컨테이너 종료됨)
```

```yaml
docker rename [기존 컨테이너 이름] [변경할 컨테이너 이름] : 컨테이너 이름 변경
```

```yaml
docker rm [container name or id] : 컨테이너 삭제
```

```yaml
docker rm $(docker ps -aq) : 모든 컨테이너 삭제
```

```yaml
docker logs [container name or id] : 컨테이너 로그 확인
```

## 볼륨

```yaml
docker volume rm [volume name] : 도커 볼륨 삭제

사용중인 도커 볼륨 삭제시 에러
```

```yaml
docker volume prune : 사용하지 않는 도커 볼륨 삭제
```

```yaml
docker volume ls : 도커 볼륨 목록 확인
```

## 도커 컴포즈

```yaml
docker compose up -d : 도커 컴포즈 백그라운드 실행(백그라운드 옵션 -d)

백그라운드 실행 안할 시 터미널 종료시 컨테이너도 같이 종료됨
```

```yaml
docker compose start : 컴포즈파일에 명시된 컨테이너 실행
```

```yaml
docker compose down : 컴포즈파일에 명시된 컨테이너 종료
```

```yaml
docker compose restart : 컴포즈파일에 명시된 컨테이너 재실행
```

```yaml
docker compose down : 도커 컴포즈 파일 중지

명령어 실행시 컨테이너 목록에서 제거됨

docker compose down -v : 도커 컴포즈 파일 중지, 볼륨 삭제
```
