# TODO 주석

[[IntelliJ] 주석 태그 & 키워드 활용하기 : TODO, FIXME, Custom Comment Tag](https://adjh54.tistory.com/386)

| 주석 태그 | 의미 | 사용 목적 |
| --- | --- | --- |
| `TODO` | 해야 할 일 | 아직 구현하지 않았거나 나중에 추가/변경할 기능 |
| `FIXME` | 고쳐야 할 문제 | 현재 코드에 문제가 있음을 명시 (bug 또는 이상 동작) |
| `HACK` | 임시로 처리한 코드 | 올바르지 않지만 현재 상황을 해결하기 위한 임시 코드 |
| `NOTE` | 중요 참고 사항 | 특정 코드에 대한 중요한 설명이나 주의할 점 표시 |
| `BUG` | 버그 있음 | 명확히 확인된 버그 위치를 코드상에 남김 |
| `OPTIMIZE` | 성능 개선 필요 | 향후 성능 최적화가 필요함을 표시 |
| `REFACTOR` | 코드 개선 필요 | 구조를 변경해야 하거나 리팩토링이 필요한 코드 |
| `DEPRECATED` | 더 이상 사용하지 않음 | 해당 기능이나 API가 더 이상 권장되지 않음 |
| `WARNING` | 주의사항 | 특정 코드 사용 시 주의가 필요함을 명시 |
| `INFO` | 정보성 주석 | 문서화 또는 내부 로직 설명용 (디버깅용 포함) |
