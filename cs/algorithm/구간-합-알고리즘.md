# 구간 합 알고리즘

### 구간합(prefix sum)

수들이 나열되어 있을때 특정 구간의 합을 뜻함

특정 구간의 합을 쉽게 해주는 알고리즘

### 합배열 만들기

1. 원본 배열(A)과 똑같은 사이즈의 배열(S)을 만든다.
2. A배열의 [0] 값을 S[0] 에 똑같이 설정한다. 
3. S[1]의 값은 S[0] + A[1] 의 값

### 합 배열을 만드는 공식

S[i] = S[i-1] + A[i]

원본 배열 A에 대해서 i~j 까지의 구간합을 구할 때

S[j] - S[i-1] → 3 ~ 8 까지 구할때 S[8] - S[2]

### 정리

1. 합 배열을 구하는 공식 S[i] = S[i-1] + A[i]
2. 구간합 질문을 합배열을 이용해 대답 S[j] - S[i-1]

```python
A = [5, 4, 3, 2, 1]
N = len(A)

# 합배열 (prefix sum)
S = [0] * (N+1)
for i in range(1, N+1):
    S[i] = S[i-1] + A[i-1]

# 구간합 (2~4 구하기, 0-based index)
i, j = 2, 4
print(S[j+1] - S[i])  # 3+2+1 = 6
```
