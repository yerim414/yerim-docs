Big-O

입력 크기(n)가 커질때 실행시간이 어떤 속도로 증가하는지 대략적으로 나태내는 수학적 표기

대략적이란건 상수나 작은 항은 버리고 성장률을 지배하는 큰 항만 남긴다는 뜻

왜 쓸까??

절대적인 시간(1초 걸려요, 2초 걸려요) 대신 입력 크기 n 이 커질때 시간이 어떻게 변하는지 보기 위해서

자주 쓰이는 Big-O 예시

**O(1)** : 입력 크기와 상관없이 항상 일정한 시간 → “즉시 처리”

**O(log n)** : 로그 함수처럼 천천히 늘어남 (이진 탐색 같은 경우)

**O(n)** : 입력이 2배면 실행 횟수도 2배 (for문 한 번 돌리는 경우)

**O(n log n)** : 정렬 알고리즘에서 자주 등장

**O(n²)** : 입력이 2배면 실행 횟수는 4배 (이중 for문 같은 경우)

```python
def print_numbers(arr):
    for num in arr:
        print(num)
```

n은 보통 입력된 데이터 크기를 말한다.

- `rr`의 길이가 10이면, 10번 출력 → `n = 10`
- `arr`의 길이가 1000이면, 1000번 출력 → `n = 1000`
    
    그래서 이 알고리즘?? 이소스의 시간 복잡도는 O(n)이다.
    

```python
for i in arr:        # n번
    for j in arr:    # n번
        print(i, j)
```

총 실행 횟수 = `n × n = n²` → O(n²)

```python
for i in arr:        # n번
    for j in arr:    # n번
	    for k in arr:  # n번
	        print(i, j, k)
```

그렇다면 이건 O(n³)
