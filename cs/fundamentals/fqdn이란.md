# FQDN이란

## FQDN(Fully Qualified Domain Name) 이란?

인터넷에서 사용되는 도메인 네임 시스템(Domain Name System, DNS)에서 특정 호스트의 **정확한 위치를 식별**하는 데 사용되는 도메인 이름의 형식입니다. 

FQDN은 호스트 이름, 도메인 이름 및 최상위 도메인(Top-Level Domain, TLD)으로 구성됩니다.

### FQDN의 구성

여기 [www.example.com](http://www.example.com) 이라는 주소가 있습니다.

이 주소의 구성은 아래와 같습니다.

- 호스트 이름: "www"
- 도메인 이름: "example"
- 최상위 도메인: "com"

호스트 이름 : 특정 네트워크에 있는 장치를 식별하는 데 사용되는 이름입니다. 

도메인 이름 : 호스트가 속한 도메인을 나타냅니다. 도메인은 일반적으로 조직의 이름이나 서비스의 이름으로 구성됩니다.

최상위 도메인 : 도메인의 최상위 수준을 나타냅니다. 주로 ".com", ".org", ".net"과 같은 것들이 있습니다.

**"www.example.com"은 "example.com" 도메인 내의 "www" 호스트를 가리키는 FQDN입니다.** 

---

그런데 FQDN은 URL이 아닌가? 라는 생각을 하게 되었다.

FQDN과 URL은 서로 다른것이다.!!

### FQDN과 URL의 차이

- FQDN은 인터넷에서 호스트나 장치를 식별하는 데 사용되는 주소입니다.
- FQDN은 호스트 이름, 도메인 이름 및 최상위 도메인(TLD)을 포함하는 전체적인 주소를 나타냅니다.

- URL은 웹 리소스의 위치를 나타내는 주소입니다.
- URL은 프로토콜(일반적으로 "http://" 또는 "https://"), 호스트명 또는 IP 주소, 포트(선택 사항), 경로 및 선택적인 쿼리 문자열을 포함할 수 있습니다.
- URL은 웹 페이지, 이미지, 동영상 등과 같은 다양한 인터넷 리소스를 식별합니다.
- "https://www.example.com/index.html"과 같은 형식을 가집니다.

요약하자면, **FQDN은 인터넷에서 호스트를 식별하기 위한 주소**이고, **URL은 웹 리소스의 위치를 지정하기 위한 주소입니다.** FQDN은 URL의 일부로 사용될 수 있습니다.
