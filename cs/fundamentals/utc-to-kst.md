# UTC to KST

데이터를 DB에 넣고 있는데 데이터 생성 시간이 현재시간보다 9시간 느리다는것을 보게 되었다.

날짜와 시간을 처리할 때, **UTC(협정 세계시)**를 기준으로 하기 때문에, 로컬 시간과 차이가 있을 수 있습니다. 한국은 UTC보다 9시간 빠르기 때문에, DB에 저장된 시간이 9시간 적은 것처럼 보이는 것입니다.

### 현재 시간 확인하기

```jsx
const now = new Date();
```

현재 PC에 설정된 시간이 나타나게 된다.

그러나 DB의 시간은 맞지 않은것인지 9시간 전의 시간이 들어간다.

그럼 DB에 값을 넣을때 9시간을 더해주면 된다.

```jsx
const offset = 1000 * 60 * 60 * 9
const koreaNow = new Date((new Date()).getTime() + offset)
```
