# 절대경로 상대경로

절대 경로와 상대 경로는 컴퓨터 시스템에서 파일 또는 디렉토리의 위치를 식별하는 데 사용되는 중요한 개념입니다. 

이 두 가지 경로 유형은 사용자가 시스템 내에서 특정 파일 또는 디렉토리에 접근하고자 할 때 중요한 역할을 합니다. 

각각의 경로 유형은 서로 다른 상황에 적합하며, 사용자에게 파일과 디렉토리에 대한 더 유연하고 효과적인 접근을 가능하게 합니다.

---

## 절대경로

절대 경로는 파일 또는 디렉토리의 전체 위치를 가리킵니다. 이 위치는 파일 시스템의 루트 디렉토리부터 출발하여 대상 파일 또는 디렉토리까지의 경로를 포함합니다.

예를 들어, 윈도우 시스템에서의 절대 경로는 **"C:\Users\Username\Documents\file.txt"**와 같이 드라이브 또는 루트 디렉토리부터 시작하여 파일이나 디렉토리를 정확하게 나타냅니다.

## 상대경로

상대 경로는 현재 작업 디렉토리나 다른 기준을 기반으로 파일이나 디렉토리의 위치를 가리킵니다. 따라서 현재 위치를 기준으로 대상 파일이나 디렉토리까지의 경로를 상대적으로 표시합니다.

예를 들어, 현재 디렉토리가 "C:\Users\Username"이고, 대상 파일이 "Documents\file.txt"라면 이것은 현재 디렉토리를 기준으로 상대적인 경로입니다.

프로젝트 디렉토리 내에서 상대 경로를 사용하면 파일 및 디렉토리 간의 관계를 유지하면서 작업을 수행할 수 있습니다. **이는 프로젝트를 다른 환경으로 이동하거나 공유할 때 유용합니다.**

상대 경로는 현재 작업 디렉토리에 의존하기 때문에 동적 환경에서 유연하게 작동할 수 있습니다. 예를 들어, 스크립트가 다른 위치에서 실행될 때도 상대 경로를 사용하여 필요한 파일을 참조할 수 있습니다.

## 상대경로 예시

1. **파일 참조**:
    - 현재 디렉토리 내에 있는 "Documents" 폴더 안의 "file.txt" 파일을 참조합니다.
    - 절대 경로: "C:\Users\Username\Documents\file.txt"
    - 상대 경로: "Documents\file.txt"
2. **상위 디렉토리 참조**:
    - 현재 디렉토리의 상위 디렉토리에 있는 "backup" 폴더 안의 "data.csv" 파일을 참조합니다.
    - 절대 경로: "C:\Users\Username\backup\data.csv"
    - 상대 경로: "..\backup\data.csv"
3. **다른 디렉토리 참조**:
    - 현재 디렉토리와 동일한 레벨에 있는 "Downloads" 폴더 안의 "document.docx" 파일을 참조합니다.
    - 절대 경로: "C:\Users\Username\Downloads\document.docx"
    - 상대 경로: "..\Downloads\document.docx"
