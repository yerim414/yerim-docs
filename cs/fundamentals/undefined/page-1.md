# Page 1

인터페이스

**인터페이스는 장비가 네트워크에 연결되는 접점이자, 트래픽이 드나드는 입구이다.**

즉 다른 네트워크와 통신하기 위한 연결 지점이다.

예를 들어 서버에 랜카드가 하나 있다면

```
Server
   │
   │ Ethernet
   ▼
eth0
```

그리고 그 eth0, 네트워크인터페이스이인에 아이피를 할당하고

```
eth0
IP: 192.168.0.10/24
```

이 인터페이스를 통해서 통신하게 된다.

```
Server
   ↓
eth0
   ↓
Network
```

그리고 그 인터페이스를 물리 인터페이스. 논리 인터페이스로 나눌수 있다.

***

## 1. 물리 인터페이스

**물리 인터페이스는 실제 장비에 존재하는 물리적은 네트워크 포트다.**

방화벽이나 지금 PC에서도 볼 수 있는것. 랜선을 꽂을 수 있는 곳이다.

물리 방화벽 장비를 보면 위 포트마다 eth0 eth1... 이 적힌 장비도 볼 수 있다.

## 2. 논리 인터페이스

**논리 인터페이스는 실제로 랜선을 꽂는 포트가 아닌, 물리 인터페이스 위에 논리적으로 생성되는 인터페이스이다.**

그리고 그 인터페이스는 사용법에 따라 이름이 다르다.&#x20;

대표적으로는 VLAN Interface, Aggregate Interface 등이 있다. 기억 나는거 몇가지 보자면

* VLAN Interface
  * 하나의 물리 포트를 가상으로 나누어 네트워크를 분리 하는 것

```
             Physical Interface
                    │
                   eth0
                    │
          ┌─────────┼─────────┐
          │         │         │
        VLAN10    VLAN20    VLAN30
          │         │         │
       10.0.10.1 10.0.20.1 10.0.30.1
```

근데 이게 방화벽 마다 부르는 방식이 다르다. VLAN, VXLAN, 아니면 그냥 port1.0 이렇게 나누는 장비도 있다.

* Aggregate Interface
  * 여러개의 물리 인터페이스를 하나처럼 묶어 사용하는 방식이다.\
    여러개의 인터페이스를 하나로 묶어 사용하면  대역폭이 증가되어 빠른 속도를 제공한다.\
    하나의 포트가 고장나더라도 나머지 정상적인 포트를 이용하여 끊김 없이 이용 할 수 있다.

```
eth0 ─┐
      ├── bond0
eth1 ─┘
```

그리고 미러링 포트 등등 많은데 체감 vlan 포트를 많이 사용한다. 그 외 것들은 잘 안쓰는거같다.
