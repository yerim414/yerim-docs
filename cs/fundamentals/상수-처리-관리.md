# 상수 처리, 관리

점점 프로젝트 규모가 커지다 보니 용어 정의를 위해 이러한 관리가 필요하다고 느꼈다.

특히 api 호출시 여러 파일에서 하나의 api를 호출한다하면.. 그 api 주소를 어디 한곳에 정의해두고 꺼내쓰는게 편하다고 생각

상수 관리 (Constants Management)

일단 `constants.py`를 만들어서 공통적인 내용부터 옮기기로 하였다.

```python
from enum import Enum

class Status(Enum):
    ADMIN = "ADMIN"
    USER = "USER"
    GUEST = "GUEST"
```

예를들어 이런 유저 권한에 관한 데이터를 상수로 만들었다. 이런 데이터는 유저의 등급에 따라 데이터 처리에 유용하므로 따로 구성하였다

에러코드의 처리도 유용할것같다.

이 방식의 **주요 목적**은 다음과 같다:

- **중복 방지**: 여러 곳에서 같은 값을 쓰더라도 한 곳에서만 관리 가능
- **가독성 향상**: 의미 있는 이름 부여로 값의 용도 명확화
- **유지보수 편의**: 나중에 값이 바뀌어도 한 곳만 수정하면 됨
- **에러 방지**: 오타로 인한 실수를 줄임 (예: `"ACTIVE"` 대신 `STATUS.ACTIVE` 사용)
