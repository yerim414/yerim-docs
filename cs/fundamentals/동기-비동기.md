# 동기 비동기

동기(Synchronous)

동기는 동시에 일어난다는 의미

프로그래밍 에서는 동기는 작업이 순차적으로 진행된다는것을 의미한다.

즉 한 작업이 시작되면 다른 한 작업이 완료될 때 까지 다른 작업은 기다리고 있어야 한다.

동기방식은 직관적인 코드를 작성하기 쉽다. 한줄한줄씩 실행되기 때문이다.

그러나 여러 작업이 동시에 실행되어야 하는경우, 앞의 작업시간이 길어 뒤에 있는 작업의 대기 시간이 늘어나는 경우 프로세스의 성능이 저하될 수 있다. → 지연의 문제

블로킹 방식, 직관적, I/O 작업에 취약

비동기(Asynchronous)

비동기는 동시에 일어나지 않는다 라는 의미이지만 프로그래밍에서는 비동기는 작업이 독립적으로 실행되며 작업 완료 여부를 기다리지 않고 다른 작업을 실행할 수 있는 방식을 의미한다.

즉 비동기 방식은 작업이 실행되면 이 작업이 끝날때까지 기다리지 않고 바로 다음 작업을 수행 할 수 있다.

주로 I/O 작업 네트워크 요청과 같이 시간이 오래 걸릴 수 있는 작업에 유용하다.

예를 들어서 크롬에서 대용량 파일을 다운로드를 기다리지 않고 우리는 검색이나 다른 페이지로 이동 등 작업을 할 수 있다. 이런게 비동기이다. 

논블로킹, 이벤트 루프, 코루틴

```python
import asyncio
import time

async def async_task(name, duration):
    print(f"{name} 시작.")
    await asyncio.sleep(duration)  # 비동기 I/O 작업(대기)
    print(f"{name} 완료.")

async def main():
    print("비동기 작업 시작")
    task1 = asyncio.create_task(async_task("작업 1", 2))
    task2 = asyncio.create_task(async_task("작업 2", 1))

    # 두 작업이 동시에(병렬로) 실행되도록 기다림
    await asyncio.gather(task1, task2)
    print("비동기 작업 완료")
```
