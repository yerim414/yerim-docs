# 클래스 변수, 인스턴스 변수

클래스 변수

- 클래스 전체에 공유되는 변수
- 모든 인스턴스가 같은 값을 참조
- 클래스 정의부에 선언하고 값을 할당한다.

```python
class MyClass:
    class_variable = 0  # 클래스 변수

    def __init__(self):
        pass

print(MyClass.class_variable)  # 0

a = MyClass()
b = MyClass()

a.class_variable = 1  # a 인스턴스에 동일 이름의 "인스턴스 변수"가 생김
print(b.class_variable)  # 여전히 0
```

`MyClass.class_variable`로 접근하면 클래스 변수를 사용한다.

`a.class_variable = 1` 처럼 값을 바꾸면, a 인스턴스에 **동일 이름의 인스턴스 변수**가 생기고 **클래스 변수와는 분리**

```python
MyClass.class_variable = 100

print(a.class_variable) # 1
print(b.class_variable) # 100
```

헷갈리는게 `a`는 **이미 이전에 `a.class_variable = 1`로 인스턴스 변수**를 만들어뒀기 때문에, `MyClass.class_variable`과는 **연결이 끊어졌음** 그래서 `MyClass.class_variable = 100` 해도, `a`는 **여전히 자기만의 1을 가지고 있음**

`b`는 여전히 인스턴스 변수에 `class_variable`이 **없기 때문에** `MyClass.class_variable`을 **참조하게 되고**, 그 값은 방금 100으로 바뀌었다.

기억해두기!!

인스턴스 변수

**각 인스턴스(객체)마다 별도로 존재하는 변수**입니다.

보통 `__init__()` 안에서 `self.변수명` 으로 선언합니다.

```python
class MyClass:
    def __init__(self, value):
        self.instance_variable = value  # 인스턴스 변수

a = MyClass(10)
b = MyClass(20)

print(a.instance_variable)  # 10
print(b.instance_variable)  # 20
```

- `self.`로 선언한 변수는 **각 객체마다 독립된 값**을 가진다.
- `a`와 `b`는 서로 다른 `instance_variable`을 가지고 있음

헷갈릴땐 `__dict__` 를 사용해서 확인해 보면 된다.
