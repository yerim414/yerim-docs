# 예외처리

프로그램 실행될 때 발생할 수 있는 예외적인 상황을 처리하여 프로그램이 갑자기 종료되는 것을 방지하고, 예외적인 상황에 대해 적절한 조치를 할 수 있게 해줍니다.

### 예외처리 구문

node에선 try~catch 인데 파이썬에서는 try~exception 이다. 헷갈린다

```python
try:
    # 예외가 발생할 수 있는 코드
    result = 10 / 0
except ZeroDivisionError as e:
    # ZeroDivisionError가 발생했을 때 실행되는 코드
    print("ZeroDivisionError 발생:", e)
except Exception as e:
    # 그 외 모든 예외를 처리하는 코드
    print("예외 발생:", e)
else:
    # 예외가 발생하지 않았을 때 실행되는 코드
    print("예외 없이 성공적으로 실행되었습니다.")
finally:
    # 예외 발생 여부와 상관없이 항상 실행되는 코드
    print("이 블록은 항상 실행됩니다.")
```

else 를 이용하여 예외가 발생지 않았을 때 실행되는 코드도 입력 가능하다.

예외의 종류

- **ZeroDivisionError**: 0으로 나누기를 시도할 때 발생.
- **FileNotFoundError**: 존재하지 않는 파일을 열려고 할 때 발생.
- **IndexError**: 리스트 등의 시퀀스에서 잘못된 인덱스를 참조할 때 발생.
- **KeyError**: 딕셔너리에서 존재하지 않는 키를 참조할 때 발생.
- **ValueError**: 연산이나 함수에 부적절한 값을 넣었을 때 발생.
- **TypeError**: 잘못된 타입의 객체에 연산을 시도할 때 발생.

파이썬에선 예외를 던질때에도 **`throw`**가 아닌 **`raise`**를 사용한다.

```python
def divide(a, b):
    if b == 0:
        raise ZeroDivisionError("0으로 나눌 수 없습니다.")
    return a / b

try:
    result = divide(10, 0)
except ZeroDivisionError as e:
    print("예외 발생:", e)
```

예외처리를 잘 처리하면 소스코드가 훨씬더 보기 좋아진다

### 예외처리의 필요성

1. **프로그램의 안정성 확보**: 예외적인 상황이 발생했을 때 프로그램이 비정상적으로 종료되지 않도록 함.
2. **오류 디버깅**: 예외 발생 시 어떤 오류가 발생했는지 추적하고 로그를 남겨 디버깅에 도움을 줌.
3. **사용자 경험 개선**: 예외 상황에 대한 적절한 대처를 통해 사용자에게 의미 있는 메시지를 제공하고, 프로그램이 계속 동작하도록 함.
