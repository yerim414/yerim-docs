추상 클래스

직접 인스턴스화 할 수 없는 클래스, 하위 클래스가 반드시 구현해야 할 메소드를 정의한다.

**메소드의 목록만 가진 클래스이며 상속받는 클래스에서 메소드를 구현한다.**

```python
from abc import ABC, abstractmethod

class UserService(ABC):
    @abstractmethod
    def get_user(self, user_id: int): pass # 추상 메서드는 호출할 일이 없으므로 빈 메서드로 만듦

    @abstractmethod
    def create_user(self, user_data: dict): pass
```

추상클래스의 사용은 abc모듈을 이용한다.
