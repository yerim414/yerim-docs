# 클래스

[__init__과 self](https://wikidocs.net/192016)

클래스의 기본 구조

```python
class MyClass:
    def __init__(self, value):
        self.value = value

    def show_value(self):
        print(f"Value is: {self.value}")
```

1. `__init__` 메서드
    
    `__init__` 은 클래스의 생성자로, 객체가 생성될때 자동으로 호출된다. 
    
    ```python
    mClass = MyClass("Test")
    ```
    
    mClass라는 객체가 만들어질 때 `__init__` 이 자동 호출 되면서 value 값으로 “Test” 를 받게 된다.
    
2. self
    
    self는 파이썬에서 클래스의 인스턴스(instance)를 나타내는 변수로 클래스를 정의할 때 메소드의 첫 번째 배개 변수로 반드시 사용되어야하는 특별한 변수이다.
    
    self를 사용하면 인스턴스 변수(instance variable)와 인스턴스 메소드(instance method)에 접근할 수 있습니다.
    
3. 인스턴스변수, 클래스 변수
    
    ```python
    class Counter:
        count = 0  # 클래스 변수
    
        def __init__(self):
            Counter.count += 1  # 클래스 변수는 클래스명으로 접근
            self.id = Counter.count  # 인스턴스 변수
    
    c1 = Counter()
    c2 = Counter()
    print(c1.id)  # 1
    print(c2.id)  # 2
    print(Counter.count)  # 2
    ```
    
    클래스 변수는 모든 인스턴스가 공유하는 변수
    
    인스턴스 변수는 각 인스턴스별로 고유한 값
