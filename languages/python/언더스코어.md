# 언더스코어(_)

**언더스코어(`_`)**, 즉 언더바의 쓰임은 **문맥에 따라 의미가 매우 다양하다.**

일단 아래와 같은 의미로도 사용 가능!

[반환값 무시](반환값-무시.md) 

1. 한 개의 앞 언더스코어 (`_var`)
    - 비공개 변수로 간주됨, 그러나 실제 private은 아니고 개발자간의 약속이다.
    
    ```python
    class MyClass:
        def __init__(self):
            self._internal_value = 42
    ```
    

1. 한 개의 뒤 언더스코어(`var_`)
    - 파이썬의 키워드와 충돌을 피하기 위한 방법
    
    ```python
    def from_(source):
        pass
    
    class_ = "MyClass"
    ```
    
    from이나 class는 파이썬의 예약어 이므로 쓸 수 없다… 
    

1. 두 개의 앞 언더스코어(`__var`)
    - **이름 맹글링(name mangling)** 을 통해 **클래스 내부용 변수로 사용**
    
    ```python
    class Test:
        def __init__(self):
            self.__secret = 123
    
    obj = Test()
    print(obj.__secret)  # AttributeError
    print(obj._Test__secret)  # 123 (우회 접근)
    ```
    

1. 앞뒤 두 개의 언더스코어 (`__var__`)
    - 파이썬 내장 변수 또는 특별한 메소드
    
    ```python
    print(__name__)       # 현재 모듈 이름
    print(obj.__class__)  # 클래스 정보
    
    def __init__(self):
    def __str__(self):
    def __len__(self):
    ```
