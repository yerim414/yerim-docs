# 해시로 파일 비교

파일 비교를 해야하는데 빠르게 비교하기 위해 해시로 변경하여 비교 하는 코드를 작성해보았다

hashlib 모듈을 사용

```python
import hashlib

def get_file_hash(file_path, hash_algorithm='sha256'):
    """주어진 파일의 해시값을 계산합니다.
    
    Args:
        file_path (str): 해시값을 계산할 파일의 경로
        hash_algorithm (str): 사용할 해시 알고리즘

    Returns:
        str: 파일의 해시값
    """
    hash_function = hashlib.new(hash_algorithm)
    
    with open(file_path, 'rb') as file:
        # 파일을 읽어 해시 함수에 입력합니다.
        for chunk in iter(lambda: file.read(4096), b''):
            hash_function.update(chunk)
    
    # 해시값을 16진수 문자열로 반환합니다.
    return hash_function.hexdigest()

def compare_files(file1, file2, hash_algorithm='sha256'):
    """두 파일을 해시값을 통해 비교합니다.
    
    Args:
        file1 (str): 첫 번째 파일의 경로
        file2 (str): 두 번째 파일의 경로
        hash_algorithm (str): 사용할 해시 알고리즘

    Returns:
        bool: 두 파일이 동일하면 True, 그렇지 않으면 False
    """
    hash1 = get_file_hash(file1, hash_algorithm)
    hash2 = get_file_hash(file2, hash_algorithm)
    
    return hash1 == hash2

# 사용 예제
file1 = 'path/to/your/first/file'
file2 = 'path/to/your/second/file'

if compare_files(file1, file2):
    print(True, "두 파일은 동일합니다.")
else:
    print(False, "두 파일은 다릅니다.")

```

파일을 한줄씩 비교하지 않고 해쉬값만을 비교하면 된다.

### 해시 알고리즘 sha256

특성

- **출력 길이:** 256비트 (64자리 16진수 문자열)
- **속도:** SHA-1보다 느리지만 충분히 빠름
- **보안:** 현재까지 알려진 충돌 공격이 없으며, 보안성이 매우 높음

사용 예시

- SSL/TLS 인증서
- 블록체인 (예: 비트코인의 해시 알고리즘)
- 디지털 서명
