# 메소드의 종류

객체지향 프로그래밍에서 가장 중요한 개념!!

1. 인스턴스 메소드(Instance Method)
    
    가장 일반적으로 사용되는 메소드, self를 첫번째 인자로 받으며, 해당 객체의 속성과 메소드에 접근할 수 있다.
    
    ```python
    class Person:
        def __init__(self, name):
            self.name = name  # 인스턴스 변수
    
        def say_hello(self):  # 인스턴스 메서드
            print(f"안녕하세요, 저는 {self.name}입니다.")
            
    
    p1 = Person("테스트")
    p1.say_hello() # 안녕하세요, 저는 테스트 입니다.
    
    # 아래의 소스는 에러 발생
    # TypeError: Person.__init__() missing 1 required positional argument: 'name'
    p2 = Person()
    p2.say_hello()
    ```
    
    p2 객체는 오류가 발생중이다. Person()을 호출할때 name 인자를 넘겨주지 않았기 때문!!
    
    해당 경우엔 name 인자를 넘겨주거나 name에 기본값을 설정 하면 된다.
    
    ```python
    class Person:
        def __init__(self, name = "홍길동"):
            self.name = name
            
    # 넘어오는 인자가 없으면 기본값 "홍길동" 으로 세팅된다.
    ```
    

1. 클래스 메소드(Class Method)
    
    클래스 자체를 대상으로 작동하는 메서드, 첫번째 인자로 cls를 받는다. 클래스 변수를 읽거나 수정할 수 있다.
    
    `@classmethod` 데코레이터를 반드시 붙여아한다!
    

```python
class Product:
    count = 0  # 클래스 변수

    def __init__(self):
        Product.count += 1

    @classmethod
    def get_count(cls):
        print(f"총 제품 수: {cls.count}")
        
 
p1 = Product() # __init__ 이 먼저 호출되므로 count가 1
p2 = Product() # 1이 더해진다. 2가됨
Product.get_count()  # 총 제품 수: 2
```

1. 정적 메소드(Static Method)
    
    객체나 클래스 상태에 의존하지 않는 독립적인 함수, 유틸 함수나 보조 함수 역할을 맡게 된다. self, cls 를 사용하지 않음 독립적임.
    
    `@staticmethod` 데코레이터 사용한다.
    
    클래스와 인스턴스 둘 다로 호출이 가능하다.
    

```python
class Math:
    @staticmethod
    def add(a, b):
        return a + b
        
result = Math.add(3, 5)
print(result)  # 8
```

## 정리: 메서드 종류 비교

| 메서드 종류 | 첫 인자 | 접근 가능 대상 | 호출 방법 | 용도 |
| --- | --- | --- | --- | --- |
| 인스턴스 메서드 | `self` | 인스턴스 변수, 메서드 | `obj.method()` | 객체 상태를 읽거나 수정할 때 |
| 클래스 메서드 | `cls` | 클래스 변수 | `Class.method()` | 클래스 수준의 동작 처리 |
| 정적 메서드 | 없음 | 없음 | `Class.method()` | 외부와 독립적인 기능 (유틸 함수) |
