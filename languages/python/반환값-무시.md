# 반환값 무시

```python
def testMethod(self, data):
	...
	return (test1, test2)
```

testMethod 라는 메소드는 리턴 값으로 `(test1, test2)` 튜플을 반환한다.

```python
test1, test2 = testMethod(data)
```

메소드를 호출하고 리턴값은 이렇게 두개를 받을 수 있다.

그런데 해당 메소드를 사용중 test1의 값만 필요하게 되었을 때 처리가 필요했음

```python
test1, _ = testMethod(data)
```

**언더스코어(`_`)** 를 써서 사용하지 않는 값을 명시적으로 무시할 수 있다.

이렇게 하면 `test2`는 무시되고, 사용하지 않는 변수 `_`는 파이썬 에서 "사용하지 않을 값"이라는 의미를 갖기 때문에 **회색 처리(= unused variable warning)** 없이 코드를 깔끔하게 유지할 수 있다.

```python
test1 = testMethod(data)[0]
```

아니면 이렇게 처리해도 된다는데.. 언더스코어가 안정성이나 가독성에서 좋은거 같다
