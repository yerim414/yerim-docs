# 동기 컨텍스트, 비동기 컨텍스트

일단 컨텍스트 매니저부터 알기 특정 작업 전후에 자동으로 실행되는 코드를 정의하고 싶을때 사용

with문을 생각하면 된다.

```python
with open("myfile.txt", "r") as f:
    data = f.read()
```

파일 열고 닫기.. 이런게 컨텍스트 매니저

아래는 동기 컨텍스트의 예제

```python
class MyContext:
    def __enter__(self):
        print(">> 자원 연결")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("<< 자원 정리")

with MyContext() as ctx:
    print("작업 중...")
```

```python
>> 자원 연결
작업 중...
<< 자원 정리
```

아래는 비동기 컨텍스트의 예제

```python
class MyAsyncContext:
    async def __aenter__(self):
        print(">> 비동기 자원 연결")
        return self

    async def __aexit__(self, exc_type, exc_value, traceback):
        print("<< 비동기 자원 정리")

async def main():
    async with MyAsyncContext() as ctx:
        print("비동기 작업 중...")

import asyncio
asyncio.run(main())
```

비동기 컨텍스트 호출 예제

```python
import aiohttp

async with aiohttp.ClientSession() as session:
    async with session.get("https://example.com") as resp:
        data = await resp.text()
```
