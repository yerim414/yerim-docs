# 환경변수 안바뀜 오류

api key가 만료되어서 재발급을 받고 .env에도 환경변수를 바꿔주웠다.

그런데 401 에러 Unauthorized 에러가 계속 발생하는것이다

print하여 환경변수 내용을 찍어보았는데 분명 .env파일에서 바꿨는데 만료된 키 값의 내용으로 출력 되고 있었다.

찾아보니 시스템 환경 변수(혹은 PowerShell 세션 환경 변수)**에 예전 키 값이 저장되어 있어서, `.env`에서 불러온 값보다 **우선적으로 사용되고 있는 상태**

라고 한다. 첨봣다 ㅜㅜ

```python
$Env:API_KEY
```

파워쉘에서 위의 명령어를 치면 이전의 키값이 출력이됨..

그냥 삭제하고 다시 실행하면 수정된 내용으로 적용된다.

```python
Remove-Item Env:API_KEY
```

위 명령어로 삭제

```python
from dotenv import load_dotenv
load_dotenv(override=True)  # 시스템 환경변수도 덮어씀
```

아니면 이렇게 해서 시스템에 기존 값이 있더라도 `.env` 값을 항상 사용하도록 한다.
