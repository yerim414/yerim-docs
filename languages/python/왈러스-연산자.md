# := (왈러스 연산자)

파이썬의 **`:=` (왈러스 연산자 / Assignment Expression)**는 **Python 3.8**부터 도입된 기능입니다.

기존에는 변수를 할당하고, 그 값을 조건문, 반복문에 바로 활용하기 위해서는 2번의 연산이 필요햇다

```python
value = input("입력하세요: ")
if value:
    print("입력값:", value)
```

`:=`를 사용하면 **표현식(표현식이란 계산의 결과가 값이 되는 코드) 안에서 동시에 변수 할당과 평가**를 할 수 있다.

```python
변수 := 값
```

변수에 값을 할당하고 그 값을 바로 반환합니다.

그래서 위의 예시를 := 로 변환하면

```python
if (value := input("입력하세요: ")):
    print("입력값:", value)
```

지피티한테 예시 몇개 물어봣는데

1. 리스트 컴프리헨션에서 값 필터링

```python
numbers = [1, -3, 5, -7, 9]
positives = [n for n in numbers if (n := abs(n)) > 0]
print(positives)  # [1, 3, 5, 7, 9]
```

1. 정규표현식 매칭 결과 캐싱

```python
import re

text = "제 나이는 25살입니다."
if (match := re.search(r'(\d+)살', text)):
    print(f"나이: {match.group(1)}")
```

1. 긴 계산 결과 재활용

```python
def expensive_operation(x):
    print("비싼 연산 실행")
    return x * 2

if (result := expensive_operation(10)) > 15:
    print("결과가 15보다 크다:", result)
```
