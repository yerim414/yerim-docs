# Truncate

**`TRUNCATE`** 명령어는 테이블의 모든 데이터를 삭제하는 데 사용됩니다.

**`DELETE`** 명령어와 유사한것 같지만 차이가 있습니다.

1. **`TRUNCATE`**는 **`DELETE`**보다 훨씬 빠릅니다. **`DELETE`**는 각 행을 순회하고 로그를 기록하여 롤백이 가능하도록 합니다. 하지만 **`TRUNCATE`**는 로그를 남기지 않고 테이블을 비우는 방식으로 동작하기 때문에 더 빠릅니다.
2. **`TRUNCATE`**는 트랜잭션을 사용하지 않습니다. 즉, 롤백이 불가능하며 실행 즉시 테이블이 비워집니다.
3. **`TRUNCATE`**는 테이블을 비우지만 테이블의 구조는 그대로 유지됩니다. 따라서 테이블의 저장 공간은 **`TRUNCATE`**를 사용한 후에도 변하지 않습니다.
4. **`TRUNCATE`** 명령에 대한 권한은 **`DELETE`** 명령과는 별개로 관리됩니다. 일반적으로 테이블을 수정할 수 있는 권한이 있는 사용자에게 **`TRUNCATE`** 권한이 부여됩니다.

```sql
TRUNCATE TABLE user;
```

**`TRUNCATE`** 명령어를 이용하여 user 테이블을 비우는 명령 입니다.
