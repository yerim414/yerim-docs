# Drop

**`DROP`** 명령어는 데이터베이스, 테이블, 뷰, 인덱스 등과 같은 데이터베이스 객체를 삭제하는 데 사용됩니다.

### 테이블 삭제

```sql
DROP TABLE USER;
```

USER 테이블을 삭제하는 명령어 입니다.

### 데이터베이스 삭제

```sql
DROP DATABASE DB_NAME;
```

DB_NAME 데이터베이스를 삭제하는 명령어 입니다.

### 인덱스를 삭제

```sql
DROP INDEX index_name ON table_name;
```

table_name 테이블의 index_name 인덱스를 삭제하는 명령어 입니다.
