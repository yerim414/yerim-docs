# Capped collection

[Capped Collections](https://www.mongodb.com/ko-kr/docs/manual/core/capped-collections/)

Capped Collection 이란?

고정된 크기를 가진 컬렌션이다 도큐먼트가 저장되는 순서대로 저장을 하며 만약 저장소가 가득 차 있을 시 가장 오래된 도큐먼트를 제거하고 새로운 도큐먼트를 저장한다.

장점 

1. 컬렉션이 미리 정해진 크기를 가지므로, 데이터가 계속 쌓이는것을 방지 할 수 있다. **메모리를 효율적으로 관리가 가능하다**
2. **로그나 임시 데이터**와 같이 이전 데이터를 유지하지 않고 최신 데이터만 유지하고 싶을때 용이하다.
3. 추가된 순서대로 데이터를 저장하므로 쿼리를 실행할 때 순차적인 읽기 작업 가능(쿼리 성능 향상)

단점

1. 데이터의 영구적인 보관이 필요한 경우 적절하지 않음
2. 새로운 도큐먼트가 추가될 때마다 인덱스를 재구성해야함
3. 도큐먼트의 크기를 수정할 수 없다
4. 도큐먼트를 삭제할 수 없으며 컬렉션 drop을 이용해야한다.

크기가 100MB인 capped 컬렉션을 생성

```jsx
db.createCollection("logs", {capped:true, size:100000000})
```

TTL 인덱스와 capped 잘 선택해야한다..
