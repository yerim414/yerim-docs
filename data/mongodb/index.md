# Index

[Single Field Indexes](https://www.mongodb.com/ko-kr/docs/v5.0/core/index-single/)

인덱스는 데이터베이스 쿼리의 성능을 향상시키기 위해 사용되는 자료 구조이다.

인덱스는 데이터베이스의 특정 필드에 대한 빠른 검색, 정렬을 가능하게 한다.

### **단일 필드 인덱스(Single Field Index)**

하나의 필드를 인덱스로 사용하는것을 단일 필드 인덱스라고 한다. 기본적으로 자동으로 설정되는 _id가 단일필드 인덱스 이다.

```bash
db.user.createIndex({"name":1})

# user 컬렉션의 name 필드에 인덱스 생성

# 1은 오름차순, -1은 내림차순

db.user.createIndex({name:1}, {background:1})

# 백그라운드 옵션을 사용하여 논블로킹 방식으로 가능
```

### **복합 인덱스(Compound Index)**

여러 필드에 대한 인덱스를 결합하여 생성한다. 복합 인덱스를 사용하면 여러 필드를 기준으로 정렬된 인덱스를 생성하여 여러 필드에 대한 검색 및 정렬을 효율적으로 수행할 수 있다.

```bash
db.user.createIndex({"name":1,"address":1})

# user 컬레션의 name, address 필드에 인덱스 생성
```

복합 인덱스 생성시 정렬 순서에 대해 고려해야한다.

위의 명렁은 (name), (name, addres) 에 대한 인덱스가 생성된다.

name필드만 조회, name및 address를 조회 할때만 인덱스를 사용 할 수있다.

하지만 address 만 조회, address 및 name 조회 할때는 인데스를 사용 할 수 없다.

**복합 인덱스를 사용하는 경우 지정된 정렬 방향은 index와 일치해야 한다.**

### 텍스트 인덱스(Text Index)

문자열 필드에 대한 텍스트 검색을 지원하기 위한 인덱스 유형이다. 이를 통해 몽고디비는 문자열 필드에서 특정 단어 또는 구문에 대한 검색을 빠르게 수행할 수 있다. 텍스트 인덱스는 대소문자를 구별하지 않고 단어를 분리하여 검색을 지원하며, 정규 표현식이나 구문 검색도 가능하다.

```bash
db.user.createIndex({ "address": "text" })

# usr컬렉션의 address 필드에 텍스트 인덱스 생성

db.user.find({ $text: { $search: "검색할단어" } })

# 텍스트 인덱스 사용시 텍스크 쿼리 연산자 사용 가능
```

### Index 생성 주의사항

1. 많은 인덱스 생성은 성능을 저하 시킨다.
    
    인덱스는 데이터베이스의 메모리 및 디스크 공간을 차지하므로, 필요 이상으로 큰 인덱스는 성능 저하를 초래할 수 있다. 인덱스의 크기를 최소화하여 필요한 필드만 인덱스화하는 것이 중요하다.
    
2. 초기에 인덱스 설정을 해준다.
    
    이미 데이터가 많이 있는 컬렉션에 인덱스를 생성하려 하면 정말 많은 시간이 걸린다. 백그라운드 옵션도 있긴 하지만 포그라운드 인덱싱보다는 작업이 더 오래 걸린다 한다.
