# find쿼리

Mysql의 select 와 같다고 보면된다. 조건을 적는게 상당히 어렵다

1. 모든 도큐먼트 조회

```jsx
db.user.find() //유저 컬렉션의 모든 값 조회
```

1. Name이 yerim인 도큐먼트 조회

```jsx
db.user.find({"name" : "yerim"})
```

1. Address에 인천이 포함된 도큐먼트 조회

```jsx
db.user.find({"address" : /인천/}) //sql의 %인천% 과가ㅌ은 역할
db.user.find({"address" : /^인천/}) //sql의 인천% 과 같은 역할(시작문자)
db.user.find({"address" : /인천$/}) //sql의 %인천 과 같은 역할(끝문자)
```

1. 나이가 10이상 25이하인 도큐먼트 조회

```jsx
db.user.find({"age" : {$gte:10, $lte:25}})
```

| $eq | 일치 하는 값 (equal) |
| --- | --- |
| $gt | 주어진 값보다 큰 값 |
| $gte | 주어진 값보다 크거나 같은 값 |
| $lt | 주어진 값보다 작은 값 |
| $lte | 주어진 값보다 작거나 같은 값 |
| $ne | 주어진 값과 일치하지 않는 값 |
| $in | 주어진 배열 안에 속하는 값 |
| $nin | 주어진 배열 안에 속하지 않는 값 |
1. 몽고디비 비교 연산자 정리
2. 부서가 마케팅 이거나 직책이 사원인 도큐먼트 조회

```jsx
db.user.find({$or :[
	{"dept" : "마케팅"},
	{"position" : "사원"}
]})

//조건은 배열로 여러개 나열한다
```

| $or | 주어진 조건중 하나라도 참이면 참 |
| --- | --- |
| $and | 주어진 조건 모두 참일때 참 |
| $not | 주어진 조건이 거짓일때 참 |
| $not | 주어진 조건 모두 거짓일때 참 |
1. $regex 연산자
    
    $regex 연산자는 정규식을 통해 값을 찾는다. 대소문자 무시 등 여러 옵션을 지정 할 수 있다.
    

| i | 대소문자 무시 |
| --- | --- |
| m | 정규식에서 anchor(^) 를 사용할 때 값에 \n 이 있다면 무력화 |
| x | 정규식 안에 있는 whitespace를 모두 무시 |
| s | dot(.) 사용할때 \n 을 포함해서 매치 |

네이버 이메일을 사용하는 도큐먼트 조회

```jsx
db.user.find({ email: { $regex: /@naver\.com$/ } })
```
