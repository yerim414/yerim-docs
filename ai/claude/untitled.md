## 2. 작업에 필요한 맥락을 제공하기

단순 지시 보다는 클로드에게 이 작업이 왜 필요한지, 현재 상황은 무엇인지 함께 제공해줘야 더 좋은 결과를 만드는데 도움이 된다고 한다.

```
응답 속도를 개선해줘.
```

위의 지시만 들어도 사람인 나도 무엇이 느린지 알 수가 없다..

```
현재 API의 평균 응답 시간이 약 2초입니다.

요청 처리 과정에서 PostgreSQL 조회가 여러 번 발생하고 있으며,
DB 조회 시간이 대부분의 응답 시간을 차지하고 있습니다.

외부 API 인터페이스는 변경하지 않고,
불필요한 DB 조회를 줄이는 방향으로 개선해줘.
```

**이처럼 작업의 배경을 알려주면 claude가 단순히 명령을 수행하는 것이 아니라 왜 이런 방향으로 작업해야하는지 이해할 수 있다.**
