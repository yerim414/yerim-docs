# Caveman

{% embed url="https://github.com/JuliusBrussee/caveman?utm_source=chatgpt.com" %}

**Caveman 스킬은 Claude가 응답하는 내용을 극단적으로 줄여 토큰사용을 줄이는 스킬이다.**

한마디로 "말을 적게 하자"의 스킬. 그동안 md에 "간결하게대답해" 라는 내용을 적었는데 그런 동작을 하는 스킬이다.

***

일반적으로 claude의 응답은 다음과 같다.

```
네, 확인해보겠습니다. 현재 문제는 데이터베이스 연결 설정에서 발생하는 것으로 보입니다. 
우선 설정 파일을 확인한 후 연결 문자열과 환경 변수를 검토하는 것이 좋겠습니다.
```

사실 네, 확인해보겠습니다. \~보입니다. \~좋겠습니다.

굳이 불필요하게 문장 연결이나 완곡한 표현을 할 필요는 없다.. 그냥 핵심만 말하면 되는데

Caveman을 적용하면 다음과 같다.

```
DB 연결 설정 문제 가능성.
.env 확인 → 연결 문자열 확인 → 환경 변수 확인.
```

Caveman은 **"Compress delivery, not intelligence"**, 즉 전달 방식만 압축하는 성격의 스킬이다.

***

그렇다고 너무 짧게 말한다고 중요한걸 말 안할까 싶은데 그렇지는 않다.

**보안경고, 되돌릴 수 없는 작업 등... 개발하면서 기본적인 것들은 경고나 설명을 한다.**
