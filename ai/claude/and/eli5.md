ELI5란?

Explain Like I'm 5 의 약자이다.

5살에게 설명하듯 쉽게 말해줘 이지만

이 스킬의 실제 핵심은

```
복잡한 내용
   ↓
사전 지식 없는 사람 기준으로 재구성
   ↓
HTML 결과물 생성
   ↓
큰 그림
   +
적은 텍스트
```

글로 길게 설명하는 대신 시각적으로 이해시키는 스킬에 가깝다.



일반 claude와의 설명 차이

새로운 프로젝트나, 어떠한 repo를 clone 받았을때 보통

```
이 프로젝트에 대해 전체적으로 분석해서 신규 개발자가 이해할 수 있도록 설명해주세요.

다음 내용을 중심으로 정리해주세요
1. 프로젝트의 목적
 - 어떤 프로젝트인가
 - 주요 기능과 역할
2. 사용 언어 및 주요 기술
 - 언어, 프레임워크
 - DB
 - 주요 라이브러리 및 인프라 기술
 - 각 기술의 사용 용도
3. 프로젝트 구조
 - 어쩌고......
```

이러한 프롬프트를 통해서 프로젝트에 대해 분석하게 될 것이다.

그럼 응답은 뭐 텍스트로 이렇게 올 것이다.

```
해당 프로젝트의 구조는 다음과 같습니다.
1. 프로젝트의 목적
 이 프로젝트는 어쩌고...
```

반면 ELI5를 사용하면

**전체 흐름을 먼저 이해할 수 있는 HTML 기반 그림 설명**을 만드는 것이 목적이기 때문에 그림으로 설명해 줄 것이다.

일단 해당 스킬의 응답은 사용방법에서 다뤄보겠다.



좀 재미있던점은 해당 스킬이 좀 복잡하거나 별도의 엔진이 따로 있나 싶었지만

```
eli5/
├── .claude-plugin/
│   └── plugin.json
└── skills/
    └── eli5/
        └── SKILL.md
```

정말 단순한 내용이다.. skill.md도 몇줄 안되는 정말 간단한 스킬이다.
