# 스킬 설치 및 사용법

## 1. Claude 실행 후 아래 명령어 입력

```
/plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail
```

마켓플레이스 추가 후 ponytail을 설치한다

## 2. 사용법

<figure><img src="../../../../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>

간단하게 /ponytail 명령어를 통해 실행 할 수 있다.

lite, full, ultra 모드를 선택 할 수 있는데 모드 별 차이는 다음과 같다

<table><thead><tr><th width="152">Mode</th><th>내용</th></tr></thead><tbody><tr><td>lite</td><td>기존 코드 스타일을 크게 건드리지 않으면서, 명확하게 과한 부분만 줄이는 방식</td></tr><tr><td>full</td><td>기본 동작 방식, 새 기능을 만들 때 무난한 모드</td></tr><tr><td>ultra</td><td>공격적으로 불필요한 코드를 줄일 때, 새 코드 작성보다 삭제와 단순화를 우선적으로 고려</td></tr></tbody></table>
